# Poster 001 · Seerah Quest has launched

Portrait poster, 1080 × 1920 (`poster.png`), for WhatsApp Status, Stories and DMs. For people who have already seen the promos, so it explains nothing about the app. It says three things:
- **Seerah Quest has launched.**
- **Founder's codes** go only to those who make the intention to register 20 people, messaging each one personally.
- **Message me** to get one.

The look: deep green and gold, a gold "Founder's code" card in 3D with its code hidden, and twenty stars for the twenty people. The card has no chip so it doesn't read as a bank card (the app is free).

## Before posting

- **"Message me" has no number or name on it**, so it works when you post it yourself. If someone else shares it, add your number to the caption.
- **Have someone check the Urdu wording.**
- Change it: edit `poster.html`, then `node tools/poster.mjs posters/001-launched`.
